# セキュリティ・データの扱い

## 方針

「石を見る」の鑑賞機能には、ログイン、データベース、APIキー、有料APIは不要です。
実際の広告SDKや広告配信への接続はありません。
石・アイコン・OG画像には、自作のコードと図形を使っています。

- 公開サイト：[石を見る](https://stone-viewer-iota.vercel.app)
- 公開リポジトリ：[shunsoco-stack/stone-viewer](https://github.com/shunsoco-stack/stone-viewer)

## 端末内の記録

鑑賞時間などの記録は、ブラウザの`localStorage`の`stone-viewer:v1`へ保存します。
保存対象は日別の鑑賞時間、累計回転回数、石のシード・名前・説明文、テーマ・回転モード・描画品質です。
日別時間は今日を含む直近30日分を保持し、端末の現地時間の午前0時で区切ります。
アカウントや別端末との同期はありません。保存領域を削除すると記録も削除されます。
保存が禁止されている場合や容量不足の場合は、メモリ内だけで動作を継続し、画面に記録を保存できないことを表示します。
保存内容は暗号化された個人用金庫ではなく、同じブラウザを操作できる人が閲覧・変更できます。
鑑賞時間はページの可視状態に基づく目安で、実際の注視や本人確認の証明には使えません。

## 計測

Vercel Web Analyticsを利用します。独自イベントは回転角度、モード、鑑賞秒数、共有方法などの最小限の値です。
氏名・メールアドレス・入力テキストを独自イベントへ送信しません。
石の名前や日別記録そのものも送信対象ではありません。ページビューのURLはクエリとハッシュを除去します。
ブラウザの`Do Not Track`が有効な場合は、ページビュー・独自イベントとも送信しません。
共有のキャンセルは成功イベントとして数えません。手動共有用の文章を表示しただけでは送信せず、コピー操作で記録します。

Vercelの独自イベント集計はPro / Enterpriseプラン向けです。
Hobby公開では`NEXT_PUBLIC_ENABLE_CUSTOM_EVENTS`を無効に保ち、追加課金の伴うアップグレードは行いません。
公開先の無料Web Analyticsは有効化済みですが、独自3イベントの送信・集計は無効です。
料金・利用制限は[公式文書](https://vercel.com/docs/analytics/limits-and-pricing)を確認してください。

## オフラインキャッシュ

Service Workerはこのアプリの同一オリジンの公開コンテンツをキャッシュします。
初回キャッシュを補うメッセージでは、同一オリジンの`/_next/static/`配下のURLだけを受け付けます。
外部オリジン、GET以外のリクエスト、`/api/`、`/_vercel/`、RSC用リクエストはキャッシュ対象にしません。
共有先への投稿やAnalytics送信を、Service Workerのオフライン処理で代行することはありません。
キャッシュ削除・保存制限・読み込み未完了の場合は、オフラインでは画面を利用できない場合があります。

## Secret Scan

リポジトリ内のソース・設定ファイルを、補助スキャナーで検査できます。

```sh
npm run secret:scan
node scripts/secret-scan.mjs --self-test
```

検査対象には、代表的なアクセストークン、秘密鍵ヘッダー、認証値、パスワードを含むURL、秘密情報らしいリテラル代入を含みます。
疑わしい値があれば終了コード1、検査そのものが失敗した場合は終了コード2を返します。
ログへ出すのはファイル名・行番号・ルール名だけです。検出した値そのものは表示しません。
セルフテストは実在する認証情報を使わず、実行時に合成した文字列で検出と伏字を確認します。

### 対象と限界

- このプロジェクトのディレクトリ配下だけを検査し、親フォルダの別プロジェクトへ移動しません。
- `node_modules`、`.next`、`.git`、`.vercel`、`.npm-cache`、`.local`、`.turbo`、`out`、`coverage`、`playwright-report`、`test-results`は対象外です。
- 画像・フォントなどのバイナリファイルは対象外です。シンボリックリンクは辿りません。
- Git履歴、エンコード・暗号化された秘密情報、あらゆるサービスのトークンを網羅するものではありません。
- 「検出なし」は「秘密情報が絶対に存在しない」という保証ではありません。

公開・更新前にはGitの差分と追跡ファイルを目視確認し、Gitleaksなどの専用スキャナーも併用します。

### 秘密情報を入れないために

- `.env*`と`.vercel/`はGitへ追加しません。公開可能な設定例は`.env.example`に限定します。
- `NEXT_PUBLIC_`で始まる値はブラウザへ渡る前提です。秘密値を入れないでください。
- GitHub / Vercelの認証情報をソース、README、スクリーンショット、テスト出力へ貼り付けません。
- 実在する秘密情報を検出した場合は、履歴から消すだけでなく、発行元で失効・再発行を行います。
- 誤検知への対応は原因を確認してから行い、広範な除外で検査を無効化しません。

## CI

`.github/workflows/quality.yml`は、依存関係のインストール後にlint、型検査、テスト、スキャナーのセルフテスト、Secret Scan、本番ビルドを実行します。
ワークフローのGitHub権限は`contents: read`に限定しています。
自動デプロイに認証情報を直書きする処理は含みません。
初回コミット`a478e2f`の[Quality & Secret Scanは成功しています](https://github.com/shunsoco-stack/stone-viewer/actions/runs/33040835487)。
最新状態は[ワークフローの実行履歴](https://github.com/shunsoco-stack/stone-viewer/actions/workflows/quality.yml)を参照してください。
E2E・公開後のPWA検証・実OSへのインストールは、このCIの検査範囲とは別です。

## 公開経路

Vercelプロジェクト`stone-viewer`はHobbyプランで、Vercel CLIによる手動デプロイで公開しています。
GitHubとの自動デプロイ連携は接続が完了していません。GitHubへのpushだけで本番サイトが更新される状態ではありません。
デプロイ時の認証はVercel CLI側で管理し、リポジトリへ認証情報を含めません。

## 報告時の注意

不具合を報告する際は、環境変数・Cookie・ブラウザの個人情報を削除した内容を共有してください。
実際のトークンや秘密鍵は、公開Issueへ投稿しないでください。
