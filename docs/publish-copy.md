## ポートフォリオ文

### 石を見る — 何もしないを、ひとつ。

画面中央の石を、ひたすら眺めるWebアプリです。
できることは、ボタンを押して石を1度だけ動かすこと。360回で、ささやかな一周記念を迎えます。
美術館や高級プロダクトのような落ち着いたインターフェースと、徹底して役に立たない内容のギャップをデザインしました。

Next.js / TypeScript / Three.jsで実装し、石の形状と質感はコードからプロシージャルに生成。
外部の3D素材や有料APIは使わず、光・影・浮遊表現で一個の石に存在感を持たせています。
本日の鑑賞時間の端末内保存、5秒間の広告風演出、禅モード、ダークモード、共有、PWAにも対応。
WebGLを使えない環境ではSVG表示へ切り替え、小さな体験を広い環境へ届けることを意識しました。

「機能を増やす」のではなく、「何もしない時間を丁寧につくる」ことに向き合った個人制作です。

技術：Next.js / App Router / TypeScript / Tailwind CSS / Three.js / PWA / Vercel Analytics

計測に関する補足：回転・鑑賞時間・共有のイベント送信処理を実装。Vercel Hobbyでは独自イベントを集計できないため、無料公開では送信を無効にし、ページビューと端末内記録を利用します。
